# Практика 2. Кварталы и метрики города: Черноголовка

Курс «Технологии ИИ в урбанистике», [задание](https://mvin8.github.io/ai-technologies-in-urbanism/content/practice/practice-02.html).
Территория — **город Черноголовка, Московская область, Россия** (8 км²).
Работа целиком выполнена ИИ-агентом (Claude Code): он написал код, скачал данные, запустил расчёты и собрал дашборд.

## Что здесь лежит

| Файл / папка | Что это |
|---|---|
| `practice02_chernogolovka.ipynb` | **Главный ноутбук**: план, запросы к ИИ, загрузка данных, кварталы, остановка с объяснением метрик, все расчёты из `pipeline.ipynb` с картами и таблицами, выводы, инструкция повторного запуска. Все ячейки выполнены, результаты видны. |
| `make_dashboard.py` | Отдельный скрипт: читает готовые GeoJSON и собирает `dashboard.html`. Ничего не скачивает и не пересчитывает. |
| `dashboard.html` | **Дашборд**: интерактивная карта (выбор любого из 30+ показателей), 7 графиков, таблицы всех показателей, выводы, источники и ограничения. Один файл, открывается в браузере. |
| `data/` | Исходные данные OSM: граница, выгрузка `chernogolovka.osm`, дороги, вода, землепользование, здания, школы (GeoJSON), пешеходный граф, `sources.json` с датами загрузки |
| `results/` | Результаты в GeoJSON: кварталы, землепользование, здания, школы, обеспеченность и связи, плотность, морфотипы, доступность, сводный `blocks_all.geojson`, а также матрица времени (CSV) и `summary.json` |
| `pyproject.toml` | Зависимости проекта (добавлены BlocksNet 1.0.0a9, plotly и др.) |

## Как запустить

Все команды для Windows, **Command Prompt** (командная строка) в VS Code, в папке проекта.

1. Активировать окружение:
   ```
   .venv\Scripts\activate.bat
   ```
2. Пересчитать ноутбук. Можно открыть его в VS Code, выбрать ядро `.venv` и нажать **Run All**, а можно запустить из терминала:
   ```
   python -m jupyter nbconvert --to notebook --execute --inplace practice02_chernogolovka.ipynb
   ```
   Готовые файлы из `data/` и `results/` читаются заново, поэтому интернет не нужен. Чтобы скачать всё с нуля, поставьте `REFRESH = True` в первой ячейке кода.
3. Собрать дашборд:
   ```
   python make_dashboard.py
   ```
4. Открыть `dashboard.html` двойным щелчком. Графики работают без интернета, а подложке карты и библиотеке карты Leaflet интернет нужен.

Если `.venv` потерялся, его можно создать заново (нужен **Python 3.12**: BlocksNet 1.0.0a9 не ставится на 3.13):
```
py -V:3.12 -m venv .venv
.venv\Scripts\activate.bat
pip install -e .
```

## Что пришлось решить по ходу

- **Python 3.13 не подошёл.** Зависимость BlocksNet `iduedu==0.4.1` требует Python ниже 3.13, поэтому установлен Python 3.12 (`py install 3.12`) и окружение создано на нём.
- **Overpass API был перегружен** (все публичные серверы отвечали 406/500/502/504). Поэтому данные OSM скачаны через официальный API OpenStreetMap, 12 кусочками, и собраны в один файл. Данные те же, отличается только способ скачивания.
- **Граф.** Готовый пешеходный граф OSM собран OSMnx из той же выгрузки, скорость 5 км/ч. Интермодальный граф по заданию не строился. Если Overpass работает, в ноутбуке можно переключить `GRAPH_SOURCE = "iduedu"`.
- **Жилые здания.** 86 % зданий в OSM размечены просто `yes`. Здание `yes` внутри жилой зоны считается жилым — это допущение, оно помечено в данных.
- **Школы.** В OSM нет вместимости, поэтому BlocksNet подставил по 250 мест на школу (в данных стоит пометка «оценка»). Дубль школы №82 (территория + здание) объединён.

## Главные выводы (подробнее — в конце ноутбука и в дашборде)

- 64 квартала. ≈ 62 % площади — «industrial»: институты научного центра РАН и промзоны. ≈ 16 % — жильё.
- Население по модели ≈ 27,6 тыс. (перепись 2021 г. — ≈ 21 тыс.; оценка завышена из-за допущения о жилых зданиях).
- Медианное время пешком между кварталами ≈ 28 мин.
- Обеспеченность школами по модели 38 %. Это результат того, что вместимость оценена минимально, а не факт нехватки.
- Застройка разреженная (средний FSI ≈ 0,26). Обе классификации показывают малоэтажные нежилые кварталы и несколько многоэтажных микрорайонов.
